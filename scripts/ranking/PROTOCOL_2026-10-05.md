# Selection-optimization protocol (frozen 2026-10-05, before any combination result)

Goal: improve WHICH watches get the resting orders / slots, using the five
feature modules in this folder, without fooling ourselves. Written and saved
before any combined ranking has been run. Do not edit after the first
candidate result; add a dated amendment at the bottom instead.

## What already exists (seen before this protocol, so NOT clean)
- Single-feature results on TRAIN 2016-09..2022-12 (scripts/ranking/harness.py,
  results/ranking_train.csv). Depth-only baseline: +76.27% / maxDD -25.96% /
  ret/DD 2.94 / 549 closed trades. Breadth (frac) had the best ret/DD (3.99,
  return +54.97%, maxDD -13.78%). No variant met the old four-part rule.
- So 2016-2022 is NOT a clean out-of-sample for anything built from these
  features. Only 2023-01-03 onward has never been scored for any ranking
  variant. That span is the LOCKBOX.

## Fixed setup for every run
Live config, 20 slots (equity/20 sizing), bucket stops 7/11/16/26/37, 63-day
exit, 10 bps slippage, 3% ADV floor, 1-2% bucket excluded, resting-limit
fill, rest-top-N by the candidate's ranking. Engine untouched
(monkeypatched). Baseline = plain depth (must reproduce 821 trades /
+177.81% / -25.96% over the full 10yr; engine's own sort).
Metric of record: return / maxDD on the mark-to-market equity curve.

## Phases
1. Outcome table: run the engine with MAX_SLOTS huge so every touch fills;
   each trade is one watch's unconstrained outcome (pnl_pct, days_held, exit
   reason). Join features. Validate by recomputing a normal 20-slot run's
   per-trade returns for trades that appear in both.
2. Diagnostics on events from 2016-09..2018-12 ONLY (the first fold's train
   set): return per slot-day (pnl_pct / days_held) by feature quintile within
   depth bucket, SEs clustered by gap_date; crowd effect outside Mar-2020.
   Purpose: mechanism check; a feature with no consistent sign is dropped
   from composites (written down, not silently).
3. Candidates (parameters fixed NOW, no tuning). Max five plus baseline:
   A  Crowd throttle: depth ranking, but a watch whose gap_date had
      breadth_frac >= 0.50 (>=50% of the universe gapped >=2% that day) may
      only rest an order while FEWER THAN 4 open positions (of any age) came
      from such crowd days. (Cap 4 = 20% of 20 slots.)
   B  Bucket-then-quality: order by depth bucket (abs gap >=10%, 5-10%, <5%)
      first; within bucket by quality = mean percentile rank, among that
      morning's live watches, of [vol_norm hi-first, vol_spike hi-first,
      breadth_frac quiet-first]; then depth; then ticker. None -> 0.5.
   C  Composite: mean percentile rank among live watches of [abs depth,
      vol_norm, vol_spike hi-first, breadth_frac quiet-first], equal weights;
      None -> 0.5; ties by depth then ticker.
   D  Learned: ridge (alpha fixed = 10, standardized features) predicting
      pnl_pct / max(days_held, 1), winsorized 1/99%, on filled outcomes from
      the training window only; features abs_gap, vol_norm, log(vol_spike),
      breadth_frac, bucket dummies. Re-fit per fold on data strictly before
      the fold. Rank = predicted value.
   E  Best of A-D (rule below) + sector cap 4 (sector_cap.make_resting_orders).
   prior_trend is excluded unless Phase 2 shows a consistent, mechanism-
   consistent sign. Both volume and trend signs were already tested; do not
   re-test the flipped sign.
4. Walk-forward folds (OOS year, trained only on strictly earlier data, for
   candidate D; A/B/C/E have no fitted parameters): 2019, 2020, 2021, 2022.
   Per fold and candidate: return, maxDD, ret/DD within that calendar year.
   Candidate passes the walk-forward if: ret/DD >= baseline in >= 3 of 4
   years AND concatenated 2019-2022 return >= 75% of baseline's AND
   concatenated 2019-2022 maxDD smaller than baseline's.
   Best of A-D for E and for the lockbox = highest concatenated 2019-2022
   ret/DD among candidates that PASS. If none pass: no lockbox run; depth-only
   stays; the breadth idea is recorded as a risk option only.
5. Lockbox: ONE candidate (the walk-forward winner, with E's sector cap only
   if E itself won), scored ONCE on 2023-01-03..2026-09-04 against baseline.
   PASS BAR: ret/DD >= 1.25 x baseline's AND return >= 75% of baseline's AND
   maxDD smaller than baseline's. Then (not part of the pass bar, reported):
   drop-SMCI, 25 bps slippage, 10-slot, and crowd effect outside Mar-2020.
6. Parity check before anything touches live: live feature code must equal
   the backtest feature on historical bars (like verify_live_engine).

## Honesty clauses
- <= 5 candidates are tried in this round; the count is reported with the result.
- 2020 holds the only deep panic in the sample; report every breadth-related
  result with and without 2020 where possible.
- Universe = today's S&P 500 (survivorship). Any win is an upper bound until
  paper fills confirm.
- TEST/lockbox numbers of non-selected candidates are never printed or saved.

## Facts found in Phases 1-2 (2026-10-05, BEFORE any candidate A-E was run)
- Outcome table (results/outcome_table.csv): 14,109 filled watches out of
  35,635 gap events. Validated against the 20-slot depth baseline: 743/821
  baseline trades reproduce exactly, 78 absent only because the engine's
  one-position-per-ticker rule blocks them in the unconstrained run, 0 differ.
- Watches by depth group are thin where the money is: only 63 watches of
  abs gap >= 10% exist in 2016-2018; per-year 10%+ counts are 11 (2021) to
  66 (2020). Year-level ret/DD comparisons are therefore noisy.
- Crowd days (>=50% of universe gapped): only 23 days in 10 years: 15 in 2020,
  4 in 2022, 1 in 2024, 3 in 2025. None in 2016-2018. Candidate A is
  effectively a rule about ~4 episodes; two of them (2024, 2025) sit inside
  the lockbox.
- Fold-1 diagnostics (gap_date <= 2018-12-31, results/diagnostics_fold1.csv):
  no feature shows a CI-excluding-zero effect in the direction the thesis
  predicts. vol_norm (5-10% group) and dd52 (5-10% group) point the OPPOSITE
  way with CIs that barely exclude zero. 10%+ group had no power (n=63).

## Amendments
### A1 (2026-10-05, owner-approved, written BEFORE any candidate A-E was run)
Replaces Phase 4. Reason: fold-level evidence is too thin (see facts above).
- A, B, C have no fitted parameters. They are scored on the full TRAIN span
  2016-09..2022-12 with per-calendar-year results shown (7 years, 2016 partial).
  QUALIFY if ALL: (i) TRAIN return >= 0.75 x baseline's; (ii) TRAIN ret/DD >
  baseline's; (iii) TRAIN maxDD smaller than baseline's; (iv) ret/DD >=
  baseline's in >= 4 of 7 calendar years.
- D (ridge) is walk-forward: for gap_date in year Y the model is trained only on
  filled outcomes with exit_date < Y-01-01; Y = 2019..2026; watches from
  2016-2018 fall back to depth order. D is judged on 2019-2022 only:
  QUALIFY if return >= 0.75 x baseline's over 2019-2022, ret/DD > baseline's,
  maxDD smaller than baseline's, and ret/DD >= baseline's in >= 2 of those 4
  calendar years.
- X = the qualifier with the highest ret/DD over 2019-2022 (the one span common
  to all candidates; for A-C it is a sub-slice of TRAIN, not clean OOS).
- E = X's ranking + sector cap 4. E replaces X only if E qualifies by the same
  tests AND its 2019-2022 ret/DD exceeds X's.
- Final = X or E. It is scored ONCE on the lockbox 2023-01-03..2026-09-04 vs
  baseline with the Phase-5 pass bar. If nobody qualifies: no lockbox run;
  depth-only stays; breadth/others recorded as risk options only.
- Candidates tried in this round: exactly five (A, B, C, D, E).
- Implementation notes (not parameters): percentile ranks are computed among
  that morning's live watches (ties averaged, None -> 0.5); B quality uses
  breadth_frac quiet-first; A counts open positions whose gap_date had
  breadth_frac >= 0.50; baseline through the new wrapper must reproduce 821 /
  +177.81% / -25.96%.
